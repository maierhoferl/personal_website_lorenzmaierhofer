Политика конфиденциальности

Последнее обновление: июнь 2026

Share2Save не собирает, не хранит и не передаёт никаких персональных данных.

  • Аккаунт не нужен. Share2Save работает без регистрации или входа в систему.
  • Без слежки. Приложение не содержит аналитики, рекламных SDK или отслеживания использования.
  • Никакие данные не покидают ваше устройство. Все загруженные файлы хранятся локально в библиотеке приложения. Ничего не отправляется на серверы разработчика.
  • Только стандартное использование сети. Загрузки используют стандартный HTTPS (iOS URLSession / Background URL Session).
  • Ваша ответственность. Приложение отображает уведомление о соответствии, напоминая загружать только тот контент, к которому у вас есть право доступа.
